# Process Lens downloads

Download the latest ready-to-run Windows x64 build from [Releases](https://github.com/HemanthMacharam/ProcessLens-Downloads/releases/latest).

## Install

1. Download `ProcessLens-1.0.2-win-x64.zip` from the latest release.
2. Extract the complete ZIP folder; do not run the app from inside the ZIP.
3. Open the extracted folder and run `TaskManager.exe`.

Requires 64-bit Windows 10 version 1809 or later, or Windows 11. The Microsoft Visual C++ Redistributable may be required. Windows SmartScreen may show a warning because the application is not digitally signed. Check the release notes and included `INSTALL.txt` for details.

A `.sha256` file is provided with each release to verify the ZIP download.
